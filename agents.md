# AGENTS.md

## Project Overview

This is a responsive restaurant website called Ember Grill.

Tech stack:
- HTML5
- CSS3
- Vanilla JavaScript

## Coding Rules

- Never rewrite files unless necessary.
- Make the smallest possible changes.
- Preserve the existing project structure.
- Do not rename files or folders unless explicitly asked.
- Do not remove comments.
- Keep the code beginner-friendly.
- Use semantic HTML.
- Use modern CSS.
- Keep JavaScript modular and readable.
- Never introduce frameworks unless requested.

## Styling

- Reuse existing CSS classes whenever possible.
- Avoid duplicate styles.
- Maintain the current color palette.
- Keep spacing consistent.

## Accessibility

- Images must have alt text.
- Buttons must be keyboard accessible.
- Maintain good color contrast.

## Before Editing

Always:

1. Explain what you plan to change.
2. Wait for confirmation before editing more than one file.
3. Warn if a change could break the layout.

## When Finished

Always provide:

- Summary of changes
- Files modified
- Anything that should be tested

## Learning Mode

Do not over-engineer solutions.

Prefer simple HTML, CSS and JavaScript.

When suggesting improvements:

- explain why
- explain what changed
- avoid advanced patterns unless requested

## File Safety

Never:

- delete files
- rename files
- move files
- install packages
- edit package.json
- edit git history

unless explicitly instructed.
